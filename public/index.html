Starting sessions

Tap a project to start a session and open it in the Claude app. Tap 💬 to run it here in the page instead — no Remote Control needed, but no images or permission prompts either.

Where they show up

In the Claude desktop app they appear under Other, not under their project folder. The app files sessions by the working directory it launched them with, and one started from outside arrives without it. Everything else — the transcript, claude --resume — works normally.

Giving them a browser

These are plain CLI sessions, so none of the desktop app's own tools come with them. Add Playwright to your CLI once:

claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest --browser chrome

Then ask for it by name — “use playwright to open…” — or the model reaches for the Claude for Chrome extension first and stops when it isn't connected. Only sessions started afterwards have it.

Screen

Tap to click and raise the keyboard, double tap to double click, hold for a right click. Two fingers scroll, pinch zooms where your fingers are. Typing goes to whatever has focus on the Mac, so tap the field there first.
